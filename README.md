# The Good Hand of God International Gospel Ministry Centre

A modern, responsive website built with Next.js for The Good Hand of God International Gospel Ministry Centre in Abuja, Nigeria.

## 🎨 Features

- **Modern Design**: Clean, professional design using the church colors (Red, White, Blue)
- **Fully Responsive**: Works perfectly on desktop, tablet, and mobile devices
- **Fast Performance**: Built with Next.js 16 and optimized for speed
- **Easy Navigation**: Intuitive menu structure with mobile-friendly hamburger menu

## 📄 Pages

1. **Homepage**
   - Hero section with church branding
   - Welcome message
   - Service times display
   - Call to action buttons

2. **About Us**
   - Church history and story
   - Apostle Oyiagaba Peter Obida's profile
   - Mission and vision statements
   - Core values
   - What we believe

3. **Ministries**
   - Children's Ministry
   - Youth Ministry
   - Women's Ministry
   - Men's Ministry
   - Evangelism & Outreach
   - Worship Ministry
   - Prayer Ministry
   - Counseling & Care
   - Media Ministry

4. **Events & Calendar**
   - Weekly service schedule
   - Special events
   - Location information

5. **Sermons**
   - Sermon archive with filtering
   - Video placeholders (ready for your recordings)
   - Podcast integration section

6. **Contact**
   - Contact form
   - Church location and contact details
   - Google Maps placeholder
   - Service times

7. **Give/Donate**
   - Multiple giving options (Bank Transfer, Mobile Money, In-Person)
   - Information about what donations support
   - Scripture references
   - FAQ section

## 🚀 Getting Started

### Prerequisites
- Node.js 20 or higher
- npm 10 or higher

### Installation

The project is already set up! Just run:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```

## 🎯 Next Steps

### Adding Content

1. **Logo/Images**: Add your church logo and images to `public/images/`
2. **Videos**: Upload sermon videos and update the sermons page
3. **Bank Details**: Update the Give page with actual bank account information
4. **Google Maps**: Add your Google Maps embed code to the Contact page

### Email Integration

The contact form is ready but needs email integration. You can use:
- [Resend](https://resend.com/) - Modern email API
- [SendGrid](https://sendgrid.com/) - Popular email service
- [FormSpree](https://formspree.io/) - Simple form backend

### Deployment

Deploy to:
- **Vercel** (Recommended): `npx vercel`
- **Netlify**: Connect your GitHub repo
- **Any hosting service** that supports Node.js
